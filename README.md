# YoZu 記憶卡

以手機體驗為核心的記憶卡 Web App。使用 FSRS 間隔重複演算法排程，資料離線保存在瀏覽器的 IndexedDB，可安裝為 PWA。

## 開發

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 單元測試（Vitest + fake-indexeddb）
npm run build      # 型別檢查 + 正式版建置（含 Service Worker）
npm run lint       # oxlint
```

## 功能

| 分頁 | 內容 |
| --- | --- |
| 複習 | 選擇牌組、今日新卡／學習中／待複習數量、翻面動畫、FSRS 評分（重來／困難／普通／簡單，顯示下次間隔）、復原、跳過、提示、語音朗讀、完成後的今日成果與「再學 10 張」 |
| 記錄 | 新增／編輯卡片：正面、提示、背面、額外資訊、正反面圖片、收藏、標籤、所屬牌組；驗證、未儲存離開提醒、⌘/Ctrl+Enter 儲存 |
| 筆記 | 全部筆記與牌組兩種檢視；搜尋、篩選（牌組／狀態／標籤／收藏／今日到期）、排序；左滑刪除、長按或「編輯」多選後批次刪除／移動；朗讀清單 |
| 標籤 | 建立、改名、改色、刪除（不會刪除卡片）、「無標籤」分類、點選查看卡片 |
| 選項 | 匯入（備份 .json、.csv／.tsv）、匯出備份、本機快照、儲存空間與持久儲存；語速、語言偏好順序、自動朗讀；學習順序、每日上限、目標記憶保持率、一天開始時間、提醒；淺色／深色／跟隨系統 |

複習頁的鍵盤快捷鍵：`空白鍵` 顯示答案（之後 = 普通）、`1–4` 評分、`Z` 復原、`→` 跳過、`R` 朗讀、`E` 編輯。

### 尚未支援（介面上已明確標示）

- **雲端同步**：需要帳號與伺服器，目前請以匯出／匯入備份在裝置間搬移資料。
- **背景推播提醒**：沒有推播伺服器，提醒只會在 App 開啟（含背景分頁）時送出。
- **Anki .apkg 匯入**：目前支援本 App 的備份檔與 CSV／TSV。

## 架構

```
src/
  db/          Dexie 資料表（schema）、資料操作（repo）、備份／匯入（backup）、首次啟動範例資料（seed）
  lib/         純邏輯：FSRS 包裝（scheduler）、今日佇列（queue）、統計、篩選排序、語音、時間格式
  store/       Zustand：設定（持久化到 localStorage）、提示訊息與確認對話框、朗讀播放器
  hooks/       即時資料查詢（dexie-react-hooks）、主題、鍵盤、提醒、未儲存保護
  components/  ui（設計系統元件）、layout（底部膠囊導覽、桌面側欄）、review、editor、notes、tags、settings
  pages/       各路由頁面；次要頁面以 lazy route 按需載入
```

設計規範（顏色、圓角、陰影、玻璃材質、品牌漸層）集中定義在 `src/index.css` 的 CSS 變數與 Tailwind `@theme`，深色模式只需切換變數。

> `.legacy-prototype/` 保存改版前的原型程式碼備份，不參與建置，確認不需要後可自行刪除。
